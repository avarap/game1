# 15 — UI/UX

## Principio
HUD mínimo durante exploración; interfaces grandes solo cuando el contexto lo requiere.

## HUD
Hora/día, energía/estado, acceso rápido y feedback contextual. Evitar paneles permanentes sin decisión inmediata.

## Interacción
Prompt cercano al objeto/NPC, acción clara y feedback de éxito/error.

## Pantallas dedicadas
Inventario/comercio, tecnología, construcción, quests/mapa. Cada pantalla debe explicar requisitos y consecuencias antes de confirmar.

## Construcción
Ghost/preview, footprint y feedback válido/inválido, rotación cuando aplique.

## Tecnología
Grafo navegable, nodos con coste y lista de desbloqueos. Estados locked/available/unlocked inequívocos.

## Comercio
Indicar qué categorías compra el NPC; no obligar al jugador a probar item por item para descubrir compatibilidad.
