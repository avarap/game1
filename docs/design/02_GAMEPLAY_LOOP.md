# 02 — Gameplay loop

## Loop principal
`Explorar → recolectar → procesar → fabricar → usar/vender → tecnología/quest → desbloquear → restaurar/mejorar → volver a explorar`.

## Loops secundarios
- Cementerio: recibir → preservar/preparar → decidir destino → mejorar rating/infraestructura.
- Agricultura: obtener semilla → plantar → esperar → cosechar → comer/vender/usar como input.
- Comercio: producir → encontrar comprador correcto → vender → reinvertir.
- Tecnología: obtener puntos/requisitos → desbloquear → abrir receta/estación/acción del mundo.
- Construcción: reunir materiales → colocar/mejorar estación → aumentar capacidad del taller.

## Diseño de fricción
La fricción es válida si enseña una futura mejora. Ejemplo: transportar troncos manualmente es aceptable al inicio si después existe carro, almacenamiento mejorado o automatización.

## Métricas a observar en MVP
- Tiempo desde recolección hasta primer producto útil.
- Número de pasos por receta.
- Frecuencia de viajes sin decisión interesante.
- Porcentaje de items con más de un uso.
- Porcentaje de desbloqueos con consecuencia visible.

## Anti-patrones
- Recursos de un único uso sin razón narrativa.
- Tecnología que solo da +5% sin abrir posibilidades.
- Viajes largos sin decisiones.
- Sistemas que no comparten recursos ni progresión.
