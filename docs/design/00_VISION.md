# 00 — Visión

## Identidad
`game1` es un RPG/management 2D original centrado en restaurar un cementerio y su entorno, transformar recursos, construir infraestructura, relacionarse con aldeanos y desbloquear sistemas mediante tecnología y quests.

## Pilares
- **Mundo que cambia:** el progreso debe verse físicamente en caminos, edificios, cementerio, taller y accesos.
- **Cadenas conectadas:** explorar → recolectar → procesar → fabricar → vender/usar → desbloquear → mejorar mundo.
- **Densidad antes que tamaño:** pocas zonas con actividades, secretos y lectura visual fuerte antes que mapas enormes vacíos.
- **Especialización económica:** cada profesión compra/vende familias coherentes de recursos.
- **Progresión logística:** tareas manuales al inicio; mejoras, transporte y automatización eliminan fricción dominada.
- **Data-driven:** recursos, cultivos, recetas, tecnologías, comerciantes, estaciones y trabajadores deben crecer principalmente añadiendo datos.
- **Originalidad:** usar referentes como benchmark de estructura, no copiar contenido protegido.

## Sensación buscada
Inicio precario y deteriorado → dominio de rutinas → taller organizado → economía local interdependiente → restauración visible → producción avanzada → automatización tardía.

## Regla de alcance
Cada nueva feature debe demostrar que refuerza al menos uno de los loops principales. Si solo añade contenido aislado, va al backlog.
