# 06 — Árbol tecnológico

## Forma
Grafo, no lista lineal. Permitir ramas y convergencias.

## Un nodo puede requerir
- tecnologías previas;
- puntos de uno o varios tipos;
- flags de quest;
- opcionalmente descubrimientos/world state.

## Un nodo puede desbloquear
- recetas;
- estaciones;
- edificios;
- items;
- resource nodes;
- merchant capabilities;
- world actions;
- mejoras de preservación/logística.

## Ramas sugeridas
Madera, piedra/construcción, minería/metalurgia, agricultura, funeraria, conservación, logística y conocimiento oculto original.

## Principio
Priorizar desbloqueos que cambien posibilidades. Bonuses porcentuales puros son secundarios.

## Ejemplo
`Conocimiento de madera → serrado → carpintería → construcción reforzada`; `Conocimiento de piedra → cantería`; ambas convergen en `infraestructura avanzada`.

## UI futura
Mostrar dependencias, coste, recompensas y nodos ocultos sin replicar visualmente ninguna referencia externa.
