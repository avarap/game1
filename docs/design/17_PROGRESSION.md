# 17 — Progresión

## Capas
1. Personal: herramientas, energía, capacidades.
2. Productiva: recetas, estaciones, velocidad/capacidad.
3. Logística: storage, transporte, rutas.
4. Social: relaciones, comerciantes, quests.
5. Territorial: restauración, accesos y zonas.
6. Tecnológica: nuevos sistemas y convergencias.
7. Endgame: automatización y cadenas complejas.

## Regla
Un buen desbloqueo debería cambiar al menos una decisión o abrir una acción nueva. Preferir `puedo hacer algo nuevo` sobre `hago lo mismo 5% mejor`.

## Curva
Inicio manual y comprensible → especialización → interconexión → reducción de tareas repetitivas → optimización de red.

## Mundo visible
Puentes, talleres, caminos, cementerio, iluminación y edificios hacen de barra de progreso física.

## Balance
Cada nueva capa debe reducir o transformar una fricción anterior para evitar acumulación de chores.
