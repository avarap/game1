# 11 — Cementerio y restauración

## Pilar propio
El cementerio debe evolucionar de espacio degradado a propiedad organizada y prestigiosa, con decisiones visibles.

## Sistemas conectados
Cadáver → deterioro/conservación → preparación → enterrar/cremar/investigar → rating/recursos/conocimiento → mejoras.

## Restauración
Vallas, caminos, iluminación, parcelas, mausoleos/edificios originales, vegetación y estaciones funerarias pueden tener estados persistentes.

## Calidad
El rating debe afectar o desbloquear algo: visitantes, quests, reputación, nuevos encargos o mejoras. Evitar que sea solo un número.

## Decisiones
Entierro, cremación e investigación deben tener costes y recompensas distintos. No crear una opción universalmente mejor.

## Feedback visual
Una mejora permanente debe cambiar escena/props/iluminación además de datos cuando sea viable.
