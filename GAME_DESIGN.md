# GAME DESIGN

## Concepto
RPG 2D de gestión, crafting, exploración y simulación con ambientación medieval original, humor oscuro y un cementerio como sistema central.

## Loop objetivo
Explorar → recolectar → procesar → fabricar → completar encargos → mejorar instalaciones → desbloquear tecnologías → acceder a nuevas zonas → conocer NPCs → descubrir historias.

## Vertical slice
El primer recorrido completo debe permitir despertar, recolectar recursos, recibir y preparar un cadáver, construir una tumba, enterrarlo, mejorar el cementerio, hablar con un NPC, completar una misión, desbloquear una tecnología, dormir, guardar, cerrar y cargar preservando el estado.

## Alcance
Se prioriza densidad y calidad sobre tamaño. No se amplía contenido hasta que los sistemas existentes sean sólidos y jugables.
